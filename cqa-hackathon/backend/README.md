# Backend (FastAPI + ML)

Здесь будет бэкенд: загрузка диалогов из API организаторов, оценка моделью по чек-листу, хранение результатов и апелляций.

Контракт API, который ждёт фронтенд, — в `../frontend/README.md` (раздел «Что фронт ждёт от бэка»).

Секреты (ключ модели, ссылка организаторов) хранить в `.env`, он в `.gitignore`:
```
ANTHROPIC_API_KEY=...
ORGANIZER_API_URL=https://...invoke?api-version=1&sp=...&sv=1.0&sig=...
```
`group_id` подставлять из запроса, не вписывать в ссылку.
