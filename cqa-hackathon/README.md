# CQA — Conversation Quality Analytics

Прототип для хакатона Freedom Broker: автоматическая оценка работы операторов поддержки по настраиваемому чек-листу. Каждый балл сопровождается объяснением и ссылкой на реплику-доказательство; оценку можно оспорить, проверяющий подтверждает или меняет её, итог пересчитывается.

## Возможности
- Загрузка набора диалогов по `group_id`, пакетная оценка с прогрессом
- Карточка диалога: транскрипт, итог, баллы по секциям, по каждому критерию — ответ, баллы, вес, объяснение, реплика-доказательство, причина N/A, флаг грубой ошибки
- Апелляции: подача с комментарием → решение проверяющего с причиной → пересчёт; видны исходная оценка, решение и финальный итог
- Редактор чек-листа: добавить / заменить / удалить критерий, вес, тип (Да/Нет, шкала, флаг), шкала с подписями, правила N/A (в т.ч. только для звонков), проверка суммы весов = 100, «Применить к набору» — переоценка только по изменённым критериям
- Аналитика: выполнение критериев, рейтинг операторов и их слабые места, распределение баллов, баллы по языкам
- Сверка с эталоном (Ground Truth): точность системы по каждому критерию и список расхождений
- Интерфейс на RU / KZ / EN; диалоги на RU, KZ, EN

## Архитектура
```
API организаторов ──► backend (FastAPI + LLM) ──► frontend (HTML/CSS/JS)
  GET ?group_id         забирает диалоги,           экраны: диалоги, карточка,
                        оценивает по чек-листу,     апелляции, чек-лист, аналитика
                        хранит результаты
```
- `frontend/` — чистый HTML/CSS/JS без фреймворков и сборки (подходит для HTML-компонента Dynamics 365). Подробности и контракт API — `frontend/README.md`
- `backend/` — FastAPI + модель. Промпт собирается из чек-листа, поэтому новый критерий применяется без изменения кода

## Запуск
**Backend**
```
cd backend
pip install -r requirements.txt
# создать .env с ANTHROPIC_API_KEY и ORGANIZER_API_URL
uvicorn main:app --port 8000
```

**Frontend**
1. В `frontend/js/config.js`: `USE_MOCK: false`, `API_BASE: 'http://localhost:8000'`
2. Открыть `frontend/index.html` в браузере (или `cd frontend && python -m http.server 5500` → http://localhost:5500)

Без бэкенда фронтенд работает на тестовых данных (`USE_MOCK: true`).

## Контрольный набор
«Диалоги» → ввести выданный `group_id` → «Загрузить набор» → «Оценить все».
